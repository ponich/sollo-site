# Світло ON — інтернет-магазин гібридних інверторів

## Ідея

Через відключення світла в Україні людям потрібне автономне живлення: щоб працювали холодильник, роутер, освітлення, насос котла, ноутбук. Конкуренти показують голий каталог із технічними характеристиками, а покупець не знає, скільки кВт і кВт·год йому потрібно. Наша перевага: **спершу допомогти порахувати, потім продати готовий комплект**.

## Цільова аудиторія

| Сегмент | Потреба | Типовий чек |
|---|---|---|
| Квартира | роутер, світло, холодильник, ноутбук на 4–8 год | 40–70 тис. грн |
| Приватний будинок | котел, насос, холодильник, плита, СЕС у майбутньому | 100–200 тис. грн |
| Малий бізнес | каса, термінал, освітлення, холодильні вітрини, 3 фази | 200+ тис. грн |

## Структура сайту (MVP)

1. **Головна (hero)**: «Світло є, навіть коли його немає», CTA «Підібрати систему» та «Каталог».
2. **Калькулятор підбору**: користувач обирає прилади та тривалість відключення → отримує потрібну потужність інвертора, ємність АКБ і рекомендований товар.
3. **Готові комплекти**: квартира / будинок / бізнес, найпростіший шлях до покупки.
4. **Каталог**: інвертори та акумулятори, фільтри за типом, фазністю й потужністю, сортування за ціною.
5. **Сторінка товару** зі своєю адресою (`/invertory/deye-sun-6k-sg05lp1-eu/`): хлібні крихти, характеристики, переваги, склад комплекту, схожі товари, форма з уже підставленим товаром.
6. **Сторінки категорій**: `/komplekty/`, `/invertory/`, `/akumulyatory/` з вступним текстом під пошукові запити.
7. **Без кошика**: продаж через консультацію. Контактна форма (ім'я, телефон, місто, спосіб зв'язку, коментар), до якої автоматично підставляється обраний товар або результат калькулятора. Поруч телефон і кнопка Telegram.
8. **Монтаж під ключ** (етапи по днях), **FAQ**, **контакти**.

9. **Наші роботи** (`/nashi-roboty/` і сторінка на кожен об'єкт): задача, рішення, результат, обладнання з посиланнями на товари, галерея фото. Блок з останніми роботами на головній, «Де ми це встановили» на сторінках товарів.

## Технічні рішення

- **Статична генерація**: `scripts/build.js` рендерить готовий HTML для всіх сторінок у `dist/` з `data/products.json` і шаблонів у `src/render.js`. Пошуковик бачить увесь контент без JavaScript.
- **Сервер**: Node.js без залежностей (`server.js`): при старті збирає сайт, віддає `dist/` з чистими URL (301 на адресу зі слешем, справжній 404), gzip, довгий кеш для CSS/JS з версією у `?v=`; приймає `POST /api/leads`.
- **Дані**: `data/products.json` (каталог, поле `slug` = адреса сторінки), `src/content.js` (тексти категорій і FAQ), `src/site.js` (назва, телефон, Telegram, години роботи, місто).
- **Заявки**: `data/leads.json` + Telegram-бот, якщо задані `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.
- **Фронтенд**: CSS + vanilla JS лише для калькулятора, фільтрів каталогу і форми. Адаптив від 360px до 1920px+.
- **Зображення**: фото з Unsplash через CDN з `srcset` (документальні, не рекламні). Фото товарів поки замінені SVG-ілюстраціями з головною характеристикою.

## SEO

| Що | Де |
|---|---|
| `<title>` до ~60 символів, `meta description` до ~160, один `h1` на сторінку | усі сторінки |
| `canonical`, `hreflang uk` / `x-default`, `robots` | усі сторінки, 404 має `noindex` |
| Open Graph (`og:title/description/image/url/type/locale`) і Twitter Card | усі сторінки, товари мають `og:type=product` і `product:price:*` |
| schema.org JSON-LD: `Store`, `WebSite`, `FAQPage`, `ItemList` | головна |
| `BreadcrumbList`, `ItemList` | категорії |
| `Product` + `Offer` (ціна в UAH, наявність, стан), `BreadcrumbList` | товари |
| `sitemap.xml` з `lastmod`, `robots.txt` з посиланням на карту і забороною `/api/` | генеруються при збірці |
| Чисті людські URL, хлібні крихти, внутрішня перелінковка (схожі товари, категорії в меню і футері) | |
| Продуктивність: статичний HTML, gzip, `srcset` + `loading="lazy"`, `fetchpriority` для hero, шрифти з `display=swap` | |

Перед запуском на домені задайте `SITE_URL=https://ваш-домен.ua` у `.env`, інакше canonical, sitemap і OG вказуватимуть на localhost. Після запуску: додати сайт у Google Search Console, надіслати `sitemap.xml`, перевірити розмітку в Rich Results Test.

Що ще варто додати для SEO: власні фото товарів (Google Merchant вимагає растрові зображення), `shippingDetails` і `hasMerchantReturnPolicy` в Offer після узгодження умов доставки й повернення, блог зі статтями під інформаційні запити, Google Business Profile для локального пошуку.

Запуск:

```bash
npm start
```

Сайт: http://localhost:3000

## Сервер і деплой

Сайт працює на Contabo (Ubuntu 26.04, 161.97.107.9) за адресою https://svitlo-on.com.

Ланцюжок: відвідувач → Cloudflare (DNS з проксі, HTTPS для відвідувачів) → Caddy на сервері (порти 80/443, сертифікат Let's Encrypt, поновлюється автоматично) → сайт на `127.0.0.1:3000`. Запити на IP-адресу і на `http://` переадресовуються на `https://svitlo-on.com` зі збереженням шляху. Так само переадресовуються `www.svitlo-on.com` і старий домен `sollo.ponich.com`.

| Що | Де |
|---|---|
| Робоча копія | `/root/apps/sollo-site` |
| Git-дзеркало | `/root/apps/sollo-site.git`, тягне гілку `develop` з https://github.com/ponich/sollo-site |
| Служба сайту | `sollo-site` (`deploy/sollo-site.service`), Node 22, `127.0.0.1:3000`, автозапуск після перезавантаження |
| HTTPS | Caddy, конфіг `deploy/Caddyfile` → `/etc/caddy/Caddyfile`; при деплої оновлюється і перезавантажується, якщо змінився |
| Автооновлення | таймер `sollo-site-update.timer` щохвилини запускає `deploy/update.sh` |
| Налаштування | `/root/apps/sollo-site/.env`: `PORT=3000`, `HOST=127.0.0.1`, `TRUST_PROXY=1`, `SITE_URL=https://svitlo-on.com`, `SITE_NOINDEX=1`, `SHOW_DRAFTS=1`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Заявки | `/root/apps/sollo-site/data/leads.json` |
| Логи сайту | `journalctl -u sollo-site -f` |
| Логи деплою | `journalctl -u sollo-site-update` |
| Логи HTTPS | `journalctl -u caddy` |

Оновлення: закомітити зміни в `develop` і запушити на GitHub.

```bash
git push origin develop
```

Протягом хвилини сервер побачить новий коміт, оновить файли, перевстановить systemd-юніти з `deploy/` і перезапустить сайт (він збирається при старті). Якщо нова версія не запустилась, `update.sh` запише в лог останні рядки помилки і поверне попередній коміт. Деплоїться лише `develop`; інші гілки сервер ігнорує.

Репозиторій публічний: `.env`, заявки, `INFO.md` і `research/` у git не потрапляють.

`TRUST_PROXY=1` бере IP відвідувача із заголовків Cloudflare, щоб ліміт заявок рахувався для кожної людини окремо, а не для Cloudflare.

Поки `SITE_NOINDEX=1`, сайт закритий від пошуковиків: усі сторінки з `noindex`, а `robots.txt` забороняє все. Перед запуском: прибрати `SITE_NOINDEX` і `SHOW_DRAFTS` з `.env` на сервері і перезапустити `sollo-site`.

Сертифікат отримується через перевірку HTTP-01: Cloudflare пропускає `/.well-known/acme-challenge/` на сервер по HTTP. Режим SSL у Cloudflare має бути Full (strict); режим Flexible дасть нескінченну переадресацію.

## Заявки в Telegram

1. У Telegram відкрийте @BotFather, надішліть `/newbot`, задайте назву. Він видасть токен.
2. Скопіюйте `.env.example` у `.env` і вставте токен у `TELEGRAM_BOT_TOKEN`.
3. Напишіть своєму боту будь-що. Якщо заявки мають бачити кілька людей, створіть групу, додайте туди бота і напишіть у групі.
4. Дізнайтеся ID чату і вставте його в `TELEGRAM_CHAT_ID`:

   ```bash
   npm run telegram:chat-id
   ```

5. Перевірте, що повідомлення доходить:

   ```bash
   npm run telegram:test
   ```

6. Перезапустіть сайт (`npm start`). У консолі має бути «Telegram: заявки надсилаються в чат».

Файл `.env` не потрапляє в git, токен нікому не пересилайте.

## Важливо перед запуском

- Додати реальні об'єкти в `data/projects.json`: `type` (apartment / house / business / lift), місто, місяць (`2026-10`), тексти задачі, рішення і результату, обладнання (`id` товарів з каталогу), фото (`/img/projects/...` у `public/` або id з Unsplash). Записи з `"draft": true` видно лише локально, з `noindex`; при збірці з `SITE_URL` реального домену вони не публікуються.

- Каталог зібрано з асортименту SOLLO (INFO.md). Ціни в `data/products.json` поки взяті з роздрібних магазинів (поле `sourceUrl`), їх треба замінити на ціни SOLLO. Товари з `"price": null` показуються як «Ціна за запитом» і не потрапляють у калькулятор. Ціна комплекту рахується автоматично: компоненти + монтажний набір (`pricing.mountingKit` у `src/site.js`: 10 000 грн для 1 фази, 63 000 грн для 3 фаз).
- Додати реальні фото товарів (зараз ілюстрації генеруються SVG).
- Підставити в `src/site.js` реальні телефон, Telegram, адресу; додати юридичні дані (ФОП/ТОВ), договір оферти та політику конфіденційності.
- Перевірити умови офіційної гарантії по кожному бренду.
